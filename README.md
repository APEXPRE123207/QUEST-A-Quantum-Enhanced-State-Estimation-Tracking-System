## What does it actually do?
It tracks things. Specifically, fast-moving things that probably don't want to be tracked. By leveraging the sheer power of **Quantum Continuous Time Particle Filters (QCTPF)** (try saying that five times fast without questioning your life choices), we calculate where an object *might* be, where it *isn't*, and where it *will be* once the superposition collapses. 

If you're looking for standard Extended Kalman Filters... sorry, we don't do peasant mathematics here. We only accept states that exist in multiple dimensions simultaneously until observed.
